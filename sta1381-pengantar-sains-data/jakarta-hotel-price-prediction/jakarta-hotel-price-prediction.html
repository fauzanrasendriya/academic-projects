Tidak ada autokorelasi yang signifikan (p > 0,05 pada uji Durbin-Watson). Meskipun transformasi meningkatkan kinerja model, masalah asumsi klasik tetap perlu diperhatikan dalam interpretasi hasil.

Karena tujuan sementara dari analisis adalah untuk prediksi, final_model (sebelum ditransformasi) dapat digunakan untuk prediksi dengan catatan bahwa interpretasi koefisien harus dilakukan dengan hati-hati mengingat pelanggaran asumsi klasik yang masih ada. Namun, jika tujuan analisis adalah inferensi, maka perlu dipertimbangkan metode lain untuk menangani pelanggaran asumsi klasik, seperti penggunaan model robust atau transformasi variabel prediktor.

6. SHRINKAGE METHODS

Shrinkage method biasanya dipakai untuk mengatasi multikolinieritas dan overfitting atau ketika banyaknya peubah lebih banyak dari pada banyak amatan. Sehingga perlu dicek apakah penggunaan shrinkage method perlu dilakukan:

Uji Multikolinieritas sudah terpenuhi dan jumlah amatan lebih besar daripada banyak peubah sehingga akan dilanjutkan untuk cek overfitting.

Cek overfitting

Cek overfitting dilakukan pada model yang sudah dilakukan best subset

# 1. Membagi Data
set.seed(123) # Agar hasil pembagian data selalu sama (reproducible)
split <- sample.split(data$h_sesudah, SplitRatio = 0.8)
train_data <- subset(data, split == TRUE)
test_data  <- subset(data, split == FALSE)

# Cek dimensi data hasil split
# print(paste("Jumlah data training:", nrow(train_data)))
# print(paste("Jumlah data testing:", nrow(test_data)))

# 2. Melatih Ulang Model HANYA pada Data Training
model_train <- lm(h_sesudah ~ rating + bintang + wilayah, data = train_data)

# 3. Fungsi untuk menghitung RMSE
calculate_rmse <- function(actual, predicted) {
  sqrt(mean((actual - predicted)^2))
}

# 4. Evaluasi Performa
# Prediksi dan RMSE pada data training
pred_train <- predict(model_train, newdata = train_data)
rmse_train <- calculate_rmse(train_data$h_sesudah, pred_train)

# Prediksi dan RMSE pada data testing
pred_test <- predict(model_train, newdata = test_data)
rmse_test <- calculate_rmse(test_data$h_sesudah, pred_test)

# Tampilkan hasil untuk perbandingan
print(paste("RMSE pada Data Training:", round(rmse_train, 2)))
## [1] "RMSE pada Data Training: 757361.13"
print(paste("RMSE pada Data Testing:", round(rmse_test, 2)))
## [1] "RMSE pada Data Testing: 745320.86"

RMSE data training dan data testing tidak jauh beda sehingga disimpulkan bahwa data tidak overfitting.

Masalah umum untuk melakukan shrinkage methods tidak terjadi, sehingga tidak dilakukan shrinkage method yang sudah dibest subset. Namun, untuk masalah pembelajaran akan dicoba untuk shrinkage method yaitu Lasso Regression untuk menyeleksi peubah (memakai model persamaan yang belum diseleksi peubahnya) harapannya model akan lebih stabil dan robust.
