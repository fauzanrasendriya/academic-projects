# Academic Projects

A collection of academic projects from Statistics and Data Science coursework at IPB University. The repository covers data visualization, time-series forecasting, statistical optimization, data science, database systems, interactive dashboards, and machine learning.

> Several projects were completed collaboratively. Team and authorship information is preserved in the original reports and infographics.

## Projects

| Course | Project | Main Focus | Key Methods / Tools |
|---|---|---|---|
| STA1262 - Visualisasi Data | [Garut Drinking Water Access Infographic](sta1262-visualisasi-data/garut-drinking-water-infographic-2023/) | Communicating household drinking-water access and conditions in Garut | Data visualization, infographic design, Excel |
| STA1262 - Visualisasi Data | [West Java Drinking Water Access Dashboard](sta1262-visualisasi-data/west-java-drinking-water-access-dashboard/) | Interactive exploration of drinking-water access across West Java | Tableau, dashboard design, CSV |
| STA1341 - Metode Peramalan Deret Waktu | [Tourist Arrivals Forecasting](sta1341-metode-peramalan-deret-waktu/) | Comparing SARIMAX and LSTM for monthly international tourist arrivals | Time series, SARIMAX, LSTM, Python |
| STA1373 - Optimasi Statistika | [USD/IDR Exchange Rate Forecasting](sta1373-optimasi-statistika/) | Optimizing an LSTM using Random Search and Particle Swarm Optimization | LSTM, PSO, sliding-window CV, Python |
| STA1381 - Pengantar Sains Data | [Jakarta Hotel Price Prediction](sta1381-pengantar-sains-data/jakarta-hotel-price-prediction/) | Predicting New Year's Eve hotel prices in Jakarta | Multiple regression, best subset, Ridge, Lasso, R |
| STA1381 - Pengantar Sains Data | [Public Service Satisfaction Analysis](sta1381-pengantar-sains-data/public-service-satisfaction-analysis/) | Identifying satisfaction factors and service groups from survey data | Factor analysis, clustering, text analysis, R/Python |
| STA1383 - Data Challenge | [DEKA Norm Database](sta1383-data-challenge/) | Building a normalized survey database and interactive norm dashboard from multi-project survey data | PostgreSQL, Supabase, SQLAlchemy, Streamlit, Python |
| STA1383 - Teknik Pembelajaran Mesin | [MyBCA Sentiment Analysis](sta1383-teknik-pembelajaran-mesin/) | Classifying mobile-banking review sentiment | KNN, FastText, TF-IDF, fuzzy KNN, Python |

Each course folder contains one or more academic projects with a dedicated `README.md`, dataset(s), analysis output, notebook, report, visualization, or application source code as available.

## Notes

- HTML reports can be downloaded and opened directly in a browser.
- Jupyter notebooks preserve the original academic workflow. Some were developed in Google Colab or Kaggle and may contain platform-specific paths that need adjustment before rerunning locally.
- Datasets and generated outputs are included where they were part of the original project files and are permitted to be published.
- Some projects use confidential or restricted datasets that cannot be included in this repository. Their code, methodology, and documentation remain available where applicable.
